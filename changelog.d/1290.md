- **An explicit id could take a number an allocation record reserved** (by `next-id`, say)
  before its item was written: `hypothesis create --id`, `measure create --id`,
  `experiment create`, `paper create` and `create_item(item_id=…)` /
  `create_item_and_push(item_id=…)` now refuse it, naming the record (`reserved by
  <allocated_by> at <time>`). Under `per_type` a record reserves its number in its own id
  space (`H-3` reserves `H-003`); under `id_numbering: global`, in every dashed id space.
  A local create checks the checkout's `_ID_ALLOCATIONS.json` and the already-fetched
  default branch's; `--push` checks origin's inside its compare-and-swap. A reserver may
  use its own number only with `$YURTLE_AGENT` set to the record's `allocated_by` (git
  `user.name` is shared by every session, so it never proves a record is yours; the
  refusal says to set `$YURTLE_AGENT` when the record names your `user.name`), and only
  in the record's own id space. Records never expire; one dropped from the file no
  longer reserves (#1290).
