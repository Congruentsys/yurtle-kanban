<!-- section: Changed -->
- **Breaking:** MCP `kanban_move_item` and `kanban_add_comment` push by default in a repo with an `origin` remote, as the CLI's `move` and `comment` have since #1279: one race-free commit on origin's copy, judged there, with the CLI's retries. Pass `"push": false` to edit locally as before; a repo with no remote is unchanged. A pushed write refused replies `{"error": ...}` as before; any other failure adds the CLI's `exit_code` (4: origin unreachable, nothing written locally). `kanban_create_item`, `kanban_update_item` and `kanban_next_id` are unchanged (#1283).
